# BMI Calculator

## Project Description
A simple Python-based BMI Calculator that calculates Body Mass Index using the user's weight and height.

## Features
- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI up to 2 decimal places
- Shows BMI category
- Validates positive weight and height values

## Formula
BMI = Weight / (Height × Height)

## BMI Categories
- Underweight: BMI < 18.5
- Normal: BMI 18.5 - 24.9
- Overweight: BMI 25 - 29.9
- Obese: BMI >= 30

## Technologies Used
- Python

## How to Run
1. Open the project in VS Code.
2. Run `bmi_calculator.py`.
3. Enter your weight in kg.
4. Enter your height in meters.
5. The BMI and category will be displayed.

## Sample Output
Weight: 60 kg
Height: 1.65 m
BMI: 22.04
Category: Normal
